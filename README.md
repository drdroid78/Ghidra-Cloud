# Ghidra Cloud

Универсальный облачный статический анализ бинарных файлов через GitHub Actions. Ghidra 12.2 Headless, JDK 25, официальный архив с закреплённым SHA-256. Стандартный ubuntu-latest runner; установка при каждом запуске.

## Запуск

[Actions → Ghidra Cloud](https://github.com/drdroid78/Ghidra-Cloud/actions/workflows/ghidra-cloud.yml) → Run workflow.

- `binary_path`: путь к разрешённому публичному бинарному файлу в репозитории (до 100 МиБ). Пустое значение запускает синтетический ELF-тест.
- `function_filter`: часть имени или адреса функции; `*` — без фильтра.
- `max_functions`: от 1 до 200, по умолчанию 50.

В завершённом запуске скачайте артефакт `ghidra-report`: `decompiled.txt`, `analysis.log`, `input.sha256`, `input-format.txt`. Срок хранения — 3 дня. Исходный файл не исполняется. Облачный runner временный; постоянен workflow, а не процесс Ghidra.

## Важно

Репозиторий, журналы и результаты публичны. Не загружайте конфиденциальные файлы, ключи, закрытые прошивки или материалы без права публикации. Анализ raw BIN требует явного определения архитектуры и адреса загрузки; текущий workflow не предоставляет такие параметры. Декомпиляция не гарантирует восстановление оригинального исходного кода. Стандартные исполнители публичных репозиториев бесплатны в рамках правил GitHub Actions, но ограничения на длительность, хранение и использование сохраняются.
